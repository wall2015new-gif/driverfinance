# 🚗 Driver Finance

> Sistema completo de gestão financeira para motoristas de aplicativo

[![Deploy na Vercel](https://vercel.com/button)](https://vercel.com)
[![Supabase](https://img.shields.io/badge/Supabase-Ready-green)](https://supabase.com)

## 🌟 Funcionalidades

### 💰 Gestão Financeira
- ✅ Registro de receitas e despesas
- ✅ **Filtro de período (Dia/Semana/Mês)** ⭐ NOVO!
- ✅ Cálculo automático de lucro líquido
- ✅ Metas diárias, semanais e mensais
- ✅ Barra de progresso visual

### 📊 Dashboard Inteligente
- ✅ Card hero com lucro do período
- ✅ Alternar entre visualizações com 1 clique
- ✅ Mini cards com métricas (horas, km, combustível)
- ✅ Gráfico semanal de ganhos
- ✅ Insights personalizados

### 🚙 Controle Veicular
- ✅ Registro de KM rodados
- ✅ Controle de abastecimento
- ✅ Histórico de manutenções
- ✅ Cálculo de consumo médio

### 📱 Comparador de Apps
- ✅ Análise de faturamento por app (Uber, 99, Indrive)
- ✅ Comparação de corridas
- ✅ Métricas de performance

### 📈 Relatórios e Exportação
- ✅ Relatórios mensais completos
- ✅ Exportação em PDF
- ✅ Gráficos detalhados
- ✅ Calendário de atividades

### 🤖 Assistente IA
- ✅ Previsões de faturamento
- ✅ Alertas inteligentes
- ✅ Sugestões de otimização

### 📲 PWA (Progressive Web App)
- ✅ Instalável no celular
- ✅ Funciona offline
- ✅ Notificações push
- ✅ Tema claro/escuro

## 🚀 Deploy

### Vercel (Recomendado)
```bash
# Instalar Vercel CLI
npm install -g vercel

# Fazer deploy
vercel
```

Ou use o botão:
[![Deploy com Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/wall2015new-gif/driverfinance)

### GitHub Pages
```bash
# Ativar GitHub Pages no repositório
# Settings → Pages → Source: main branch
```

Acesse em: `https://wall2015new-gif.github.io/driverfinance`

## 📦 Instalação Local

```bash
# Clonar repositório
git clone https://github.com/wall2015new-gif/driverfinance.git

# Entrar na pasta
cd driverfinance

# Abrir no navegador
# Windows:
start index.html

# Linux/Mac:
open index.html
```

## 🎯 Como Usar

1. **Abrir o app** - index.html no navegador
2. **Registrar ganhos** - Clicar em "Ganho" ou "Corrida"
3. **Registrar gastos** - Clicar em "Gasto" ou "Abasteci"
4. **Ver período** - Usar botões Hoje/Semana/Mês
5. **Acompanhar metas** - Visualizar progresso no card hero
